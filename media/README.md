# Video pro web

Do této složky nahrajte:

- `dilna.mp4` — video ze svařovny/dílny (formát MP4, kodek H.264, doporučeno do cca 30–50 MB kvůli rychlému načítání)
- `video-poster.jpg` — náhledový obrázek videa (snímek z videa, poměr stran 16:9, např. 1280×720 px)

Stačí soubory přejmenovat přesně na tyto názvy a nahrát sem — na webu (sekce "Video") se zobrazí automaticky, nic dalšího není třeba upravovat.

Pokud budete chtít více videí nebo jiné názvy souborů, dejte vědět.
